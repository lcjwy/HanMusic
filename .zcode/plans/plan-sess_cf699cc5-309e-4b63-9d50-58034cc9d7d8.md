# HanMusic MVP 代码落地计划（dev 分支）

依据 `doc/01-技术架构要求.md`（MVVM + GetX、依赖极简）、`doc/03-功能说明文档.md`，本轮交付 **MVP（v0.1）：F1 本地曲库 + F2 网络源（通用适配器）+ F3 播放器核心 + F4 睡眠定时 + F8 多端构建**，另含支撑 F2 的最小设置页。不含 F5 歌单 / F6 历史 / F9 B站 / F10 AI。

## 0. Git
- 从 `main` 创建 `dev` 分支；每个阶段独立 commit（`feat: ...`），完成后 `git push -u origin dev`。

## 1. 工程基础（Phase A）
- `flutter pub add`：`get`、`just_audio`、`just_audio_background`、`audio_session`、`file_picker`、`get_storage`、`http`、`audio_metadata_reader`（纯 Dart 读 ID3/FLAC/MP4 标签与内嵌封面）、`just_audio_media_kit`（Windows/Linux 播放后端）。
- 建目录骨架：`lib/app/{core/{constants,theme,utils,exceptions},data/{models,repositories,sources},services,modules/{library,online,player,settings},routes}`。
- core：路由常量、亮/暗主题、时长格式化工具、统一异常（`AppException`）、`KeyValueStore` 抽象（GetStorage 实现 + 内存实现供测试）。
- `main.dart` 重写：GetStorage 初始化 → `AudioService.init`（just_audio_background）→ 全局服务 `Get.put(permanent)` → `GetMaterialApp`（themeMode 绑定设置服务、命名路由）；桌面端条件初始化 `JustAudioMediaKit.ensureInit()`。

## 2. 模型与全局服务（Phase B）
- `Song` 模型：id/标题/歌手/专辑/时长/封面/source(local|online|bili)/pathOrUrl/addedAt，含 toJson/fromJson/copyWith；`PlayMode` 枚举（顺序/列表循环/单曲循环/随机）。
- `SettingsService`：主题模式、网络源配置（baseUrl+搜索/取址路径+字段映射）、播放模式记忆、上次播放状态。
- `LibraryService`：曲库索引持久化、按路径去重、启动时存在性校验。

## 3. 播放器核心 F3（Phase C）
- 纯逻辑类 `PlayQueueManager`：给定队列+模式计算上/下一曲（顺序至队尾停止、随机不与上一首重复、单曲循环），可脱离音频库单测。
- `PlayerService` 封装 `just_audio`：Rx 状态（queue/current/playing/position/duration/mode），`playQueue(list,index)`/seek/音量；本地=文件 URI、在线=HTTP 流同一入口；播放失败提示并自动跳下一曲（可关）；退出记忆队列与进度，启动恢复但不自动播放。
- UI：`modules/player`（播放页：封面占位/进度条拖拽/上下曲/播放暂停/模式切换/音量/定时入口）+ 全局 `MiniPlayerBar`；主框架 `modules/home` 自适应壳：宽屏 NavigationRail、窄屏底部导航，3 个 Tab（本地/在线/设置）。
- 平台接入：AndroidManifest 增加前台服务与 `WAKE_LOCK`/`FOREGROUND_SERVICE(_MEDIA_PLAYBACK)` 权限、AudioService 声明、`MainActivity` 改继承 `AudioServiceActivity`、音频读取权限（`READ_MEDIA_AUDIO` + `READ_EXTERNAL_STORAGE maxSdk 32`）；iOS/macOS Info.plist 后台音频。

## 4. 本地音乐库 F1（Phase D）
- `file_picker` 单文件/多文件/文件夹导入 → `audio_metadata_reader` 读标签与封面（失败文件名兜底），进度提示可取消；按路径去重。
- `modules/library`：虚拟化列表 + 关键字搜索（标题/歌手/专辑）+ 排序；空态/加载态组件；多选删除（二次确认，仅移除索引）。
- 点击列表项 → 生成队列交给 PlayerService。

## 5. 网络音乐源 F2（Phase E）
- `data/sources/remote/`：通用适配器（baseUrl + searchPath + playUrlPath + JSON 字段映射，提供默认值），不绑定任何平台。
- `OnlineSourceService`：搜索防抖 500ms + 旧请求结果丢弃；取播放地址失败/超时映射为可读提示（超时/无法连接源/无可用地址）。
- `modules/online`：搜索页 + 结果列表 + 未配置源的引导空态；设置页源配置表单 + 「测试连接」。

## 6. 睡眠定时 F4（Phase F）
- `TimerService` 与播放器解耦：墙钟倒计时（注入时钟可测）、预设 15/30/60/90 分钟 + 自定义 +「播完当前歌曲后停止」、新设定覆盖旧任务、顺延 10 分钟、到点调用 PlayerService 暂停；迷你条/播放页显示剩余时间。
- 播放页定时面板弹窗。

## 7. 设置页（F7 最小集）
- 主题（跟随系统/亮/暗）、网络源配置、数据管理（曲库索引清空，二次确认）、关于（版本号）。

## 8. 质量与验收（Phase G）
- 替换模板 `widget_test.dart`；新增单测：Song 序列化、PlayQueueManager 模式逻辑、TimerService（fake_async + 注入时钟）、KeyValueStore 内存实现验证 SettingsService。
- `flutter analyze` 零警告；`flutter test` 全绿；`flutter build windows` 与 `flutter build apk --debug` 构建通过。
- 文档收尾：01 选型表将 `audio_metadata_reader`、`just_audio_media_kit` 转正并补变更记录（v0.3）；README 改为项目简介 + 文档链接。
- 全部完成后推送 `dev`。

## 验收对照（MVP 清单）
本地导入→曲库→播放→Android 后台/锁屏可控；源配置后可搜索串流播放、断网有提示；四种模式行为正确并恢复上次播放；三种定时方式到点停止；5000+ 列表虚拟化流畅；空/加载/错误态覆盖。
